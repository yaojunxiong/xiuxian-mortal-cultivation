# JapaneseAudioLesson

A simple SwiftUI Japanese audio lesson app.

## Features

- Tap each Japanese sentence to play native Japanese speech.
- Uses iOS built-in `AVSpeechSynthesizer`.
- Card-style lesson layout.
- Includes sample content from Lesson 1 style sentence patterns and examples.

## How to use in Xcode

1. Open Xcode.
2. Create a new iOS App project.
3. Choose SwiftUI.
4. Name the project `JapaneseAudioLesson`.
5. Replace the generated `ContentView.swift` with `JapaneseAudioLesson/ContentView.swift` from this repository.
6. Replace or add `JapaneseAudioLessonApp.swift` if needed.
7. Run on iPhone Simulator or a real iPhone/iPad.
